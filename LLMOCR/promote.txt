# 任务
你正在处理一本昆虫学（膜翅目形态学）词典的扫描页图片。请提取该页所有词条的结构化信息。

# 页面版式规则
- 页面分左右两栏，阅读顺序为：先左栏从上到下，再右栏从上到下。
- 每个词条以加粗英文词头开头，紧跟圆括号内的形态变体说明（如复数 pl.、形容词 adj.、词根变体等）。
- 词条定义文本之后，部分词条配有一张线条插图（形态学结构图），插图与其所属词条之间无边框分隔，但通常紧邻排布，直到下一个词头出现前。
- 并非所有词条都有配图，请勿强行匹配。

# 输出要求
对页面上每一个词条，输出以下字段（JSON数组，每个词条一个对象）：

```json
{
  "term": "词头原文，仅主词形，如 areola",
  "variants": "圆括号内的完整变体说明原文，如 'pl., areolae; adj., areolate'，如无则为空字符串",
  "definition": "定义正文，保留原文措辞与专业术语，严禁任何改写或规范化拼写；如有 'see also X' 交叉引用，保留在文本末尾",
  "has_figure": true/false,
  "figure_bbox_approx": "若有配图，给出该插图在整页图像中的大致边界框，格式 [x_min, y_min, x_max, y_max]，每个值均为相对比例（范围 0.0 ~ 1.0，表示占整页宽或高的比例），例如 [0.15, 0.52, 0.50, 0.77]；若无配图则为 null",
  "column": "left 或 right",
  "reading_order": 页面内阅读顺序的整数序号，从1开始
}
```

# 严格约束
1. 严禁规范化或"修正"拉丁学名、缩写、连字符构词（如 apico-、-ico- 这类词根片段），逐字逐词忠实保留原文内容和排版。
2. 不要因为版面原因把定义文本合并到相邻词条或截断，若某词条定义因页面边界不完整，请在 definition 末尾加 "[TRUNCATED]" 标记。
3. 若一个词条本身是另一词条下的复合词条（如同一词头下有子术语，例如 base 和 basitibial plate 出现在同一段落式条目中），请拆分为两个独立对象，但在 definition 中保留原始上下文关系。
4. 图片是纯手绘线条图（无灰阶照片），若某图明显被相邻两个词条共享或位置存疑，在 definition 后追加字段 "figure_note" 说明你的判断依据，不要沉默地选择其中一个。
5. figure_bbox_approx 的每个坐标值必须是 0.0 ~ 1.0 之间的比例值（相对于整页宽高），严禁输出像素坐标或其他未经注明的单位。
6. 只输出提示词要求的目标 JSON，不要任何其他说明文字。
